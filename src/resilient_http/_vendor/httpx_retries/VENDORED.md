The Python source files in this directory are an unmodified snapshot of the
`httpx-retries` 0.4.6 wheel. They are private implementation details of
`resilient_http`; applications must import the public API from
`resilient_http`, not from this package.

When updating this snapshot:

1. Select an upstream version compatible with every supported Python version.
2. Replace the upstream Python files and `py.typed`.
3. Copy the upstream license without removing its copyright notice.
4. Record the new version, tag, commit, import date, and any local patches here.
5. Update the source checksum test and run the upstream conformance tests.
6. Build the wheel and confirm that it contains this license and does not
   expose a top-level `httpx_retries` package.
